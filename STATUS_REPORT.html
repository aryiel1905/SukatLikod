System Workflow
1
User Opens the Web App Browser
The user visits the Uprightly web app (Vercel-hosted). The browser requests camera access. Upon grant, the live webcam stream is initialized via the HTML5 Video API and fed into a canvas element for frame extraction.
getUserMedia() HTMLVideoElement React state: idle → detecting
2
Pose Estimation via MediaPipe Vision ML
Each video frame is passed to the MediaPipe Pose Landmarker Lite model (5.6 MB, loaded from /public/models/). It returns 33 3D body landmarks — including shoulders, hips, nose, ears, and elbows — with normalized (x, y, z) coordinates and visibility scores.
pose_landmarker_lite.task 33 landmarks x · y · z + visibility
3
Orientation Detection Frontend Logic
The system classifies the user's camera orientation — front, side_left, side_right, or back — using landmark visibility patterns and depth ratios. A 12-frame voting window smooths rapid transitions. The UI displays guided instructions to help the user maintain the correct capture angle.
orientationVotesRef ORIENTATION_VOTE_WINDOW = 12 smoothedOrientationLabel()
4
Feature Extraction Signal Processing
From the 33 landmarks, four posture features are computed per frame and accumulated in a 30-frame rolling buffer. Exponential Moving Average (EMA, α = 0.25) is applied to reduce noise before transmission to the backend.
trunk_angle head_forward shoulder_tilt trunk_variance EMA α=0.25 30-frame buffer
5
Backend Inference via FastAPI ML Server
The smoothed feature vector is sent as a JSON POST to the /predict endpoint on the Render-hosted FastAPI server. A trained RandomForest pipeline (StandardScaler → RF, 250 estimators) classifies the posture as proper or needs_correction, along with per-class probabilities. A 7-frame server-side voting window adds further temporal stability.
POST /predict RandomForestClassifier 7-frame voting confidence score 0–1
6
Feedback & Display UI Response
The prediction response is rendered in real time on the dashboard: a posture score (0–100), confidence bar, color-coded metric cards, and a contextual text cue (e.g., "Straighten your back," "Bring your head back"). If posture is poor for more than 9 seconds, an optional audio alert fires. The user can adjust sensitivity thresholds via calibration sliders at any time.
posture score audio cooldown 9s sensitivity sliders pill: good / fix / error
